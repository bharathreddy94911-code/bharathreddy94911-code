### Featured Projects

#### 🧠 NarrativeNexus
> AI-powered document analysis platform for PDFs, DOCX, and TXT files — from raw text to structured insight in one pipeline.

**Tech:** Flask · PyTorch · Vanilla JS · Tailwind CSS

**What it does**
- Runs an LED-based summarization model, BERT for named entity recognition and sentiment analysis, and LDA/NMF for topic modeling — all on user-uploaded documents
- Handles multi-format document ingestion (PDF/DOCX/TXT) with a full processing workflow and authentication
- Presents results through interactive visualizations rather than raw model output

#### ⚡ Magic MCP
> An AI-driven UI generation platform: describe a component in natural language, get working frontend code.

**Tech:** Model Context Protocol (MCP) · AI Agents

**What it does**
- Uses MCP architecture to let AI agents generate responsive frontend components from natural language prompts
- Integrates reusable component libraries so generated UI stays consistent, not one-off throwaway code
- Automates a step of frontend development that's normally manual and repetitive
